# TrendyTech Website

Public pages for TrendyTech projects, published from the root of the `main` branch to <https://trendytech.info/> with GitHub Pages.

## Pages

- `/` and `/privacy/` — Campaign Insights Connector public information and privacy
- `/games/` — Pipe Craft and Zombie Carnival information and privacy
- `/PipeCraft/` and `/ZombieCarnival/` — existing localized game privacy pages
- `/apps/qurankareem/` — Quran Kareem app, localized help, privacy, account deletion, and terms
- `/quran-ai-guide/` — multilingual Quran Kareem AI key guide
- `/app-ads.txt` — app advertising declaration

The Campaign Insights application itself is maintained separately; this repository contains the public website pages for it and the other TrendyTech projects.
